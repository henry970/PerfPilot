Variables and test data

Use ${name} in URLs, headers and bodies. Extractors can read a token with json:path, regex:pattern, header:Name, cookie:Name or auto. Each user keeps its own variables, so extracted tokens never leak between users. Built-ins: ${__userId}, ${__loop}, ${__random}, ${__uuid}, ${__timestamp}, ${__urlencode:name}.
